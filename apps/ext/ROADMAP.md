# Roadmap

High-level direction aligned with the project goals.

## Near term

- Firefox support via WXT build target
- Expand analysis engine with more render cause patterns
- AI-powered optimization suggestions (Claude, OpenAI, Ollama)

## Medium term

- Cloud sync (Dropbox, Google Drive, S3)
- Plugin system for custom analysis passes
- 3D component tree visualization
- TensorFlow.js render time predictions

## Ongoing

- Performance and memory optimization
- Accessibility passes on panel views
- Documentation and examples
